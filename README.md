# cataScience in your browser

Open the workshop app: **https://shanlong-who.github.io/cata/**

Open the classic app: https://shanlong-who.github.io/cata/classic/

For a class in Simplified Chinese, use the
[Chinese workshop](https://shanlong-who.github.io/cata/?lang=zh) or the
[Chinese classic app](https://shanlong-who.github.io/cata/classic/?lang=zh).
Select **中文** or **English** in the navbar at any time. Switching languages
keeps the current lesson, loaded data and quiz progress. A language selected
on the startup screen also applies to the classroom.

Both editions use cataScience 2.2.0 and run R in your browser with Shinylive.
You do not need to install R. The first visit downloads the R runtime and
packages. A visible English/Chinese startup screen shows real download
progress, prepares files with four concurrent downloads, and offers retry
and local-R instructions if startup fails. Uploaded data are processed in your
browser. External links open the websites they name.

The workshop includes a connected data workflow, public health teaching
examples, charts, and HTML report/dashboard and reproducible project exports.
The classic edition retains the original learning path.

kNN imputation requires the local R app with the optional VIM package.
VIM's xgboost dependency cannot load in this browser runtime. Other
missing-value methods and the mice multiple-imputation lesson are included.

Source and documentation: https://shanlong-who.github.io/cataScience/

## Updating this deployment

The source lives in https://github.com/shanlong-who/cataScience.
Run its `Build Shinylive apps` workflow, download the
`cataScience-shinylive` artifact, and test both editions before deploying its
contents here. The build is generated by `pkgdown/build-shinylive.R`.
`build-info.json` records the package version, source commit and runtime.

For a local build, run from the cataScience package root:

```r
source("pkgdown/build-shinylive.R")
```

The package's MIT licence and image attribution apply to the app sources.
Shinylive, webR and bundled R packages retain their respective licences.
